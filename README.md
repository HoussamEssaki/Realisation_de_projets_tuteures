# Academic Projects — E-commerce, AI and Security

This repository presents an academic project concept centered on an e-commerce platform that explores the use of AI-related capabilities alongside application and data security considerations.

## Project concept

The proposed platform aims to provide an online shopping experience with ideas such as:

- Personalized product recommendations.
- Machine-learning and deep-learning concepts.
- Image-based product recognition and visual search.
- Security considerations for application data and network communication.

These items describe the project's stated scope and should not be interpreted as production-ready or fully implemented features without checking the source code.

## Areas of exploration

| Area | Project direction |

| Cybersecurity | Application, data and network security considerations |
